本次优化说明

一、原方案的主要问题

1. 建卷链路太长且没有反馈：弹窗选模式 → 整页配置 → 点「开始抽题」右侧才出现内容，但「确认」从头到尾都可点，用户不知道还差什么。

2. 两种模式边界糊在一起：自动抽题的结果又能「新增 / 删除 / 上下移 / 改分值」，等于退化成手动；手动模式又把选题藏在同一个右栏里分步切换，看不出自己在第几步。

3. 弹窗是空转一步：卡片没有选中态，两个选项差异只有一句描述，确认按钮不随选择变化。

4. 列表缺运营动作：状态只能看不能改、没有复制、删除无保护；三条数据却显示 50 页，分页与数据量自相矛盾。

5. 配置读不懂：题型配额「20 / 50 得分 2」三合一；总分是个禁用输入框，而不是计算结果的呈现；没有题库余量提示，抽不满只能最后报错。

二、改了什么

原设计改为
状态下拉筛选顶部计数分段，一次点击
状态只能看行内开关，启用/停用即时生效
删除无保护被考试引用时置灰 + 说明原因
题数、总分两列合并为「21 题 · 100 分」
三个筛选 + 查询按钮输入即筛，保留重置
弹窗空转确认默认选中，随选择点亮
整页配置 → 抽题左配置右成卷的常驻双栏
抽题后可增删自动模式只给「换一题 / 移出」
手动模式分步藏抽屉选题 + 跨页保留已选
模糊「确认」草稿 / 预览 / 保存并启用

三、关键交互规则

· 分值实时联动：改题数或每题分值，小计与合计立刻重算；不等于 100 分时给出黄色提示而不是拦住。

· 题库余量前置：规则表直接显示每类可抽题数，抽题时不足则按上限生成并提示。

· 模式切换保留已选：从自动切到手动，题目全部继承，可继续增删排序。

· 离开保护：有未保存内容时退出需二次确认。

· 状态机：草稿 →（补全题目）→ 启用 →（被考试引用则锁定结构）→ 停用；启用中的试卷编辑时提示将影响进行中的考试。

四、可继续打磨

· 题目卡片支持拖拽排序与按题型/难度一键重排。

· 抽题支持「知识点覆盖率」与「上次已考题目降权」。

· 试卷版本记录，支持查看「本次修改了哪几道题」。

提示：右上角开关「设计标注」，画面上会出现编号气泡，悬停可看该处的设计理由。
